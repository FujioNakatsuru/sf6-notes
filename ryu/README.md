
# リュウ（Ryu）

## 通常技
- 5LP  
  踏み込んで,波掌撃に繋げる.
- 2MP  
  置きで強い
- 5MP  
  置きで強い.意外と差し返されにくい.
- 2MK  
  強い  
  `2MK > M波動拳`は連続ガード  
  `2MK > L波動拳`はDIを返せる  
- 5HP  
  当てに行く時の基本
- 5MK  
  追ってくる相手に使う  
  ゲージ消費後に使う  
  当てに行く技ではない
- 6HP  
  追ってくる相手に使う
- 6HK  
  強い  
  触りに行くときの技。当たっていたら竜巻旋風脚  
  近くなければ確定反撃されない(-4F)  
  カウンターヒットでもコンボにいける。`6HK > 5LP > 623P`　※PCなら2MPが入る

## 必殺技
### 波動拳
- M, H波動拳  
  ニュートラルの牽制、ゲージ稼ぎ
- L波動拳  
  M, H をPPされる場合はL波動拳を使う
- OD波動拳  
  相手の飛び道具が多い場合に使う。相手がよく動いていたら触りに行くよりもリスクが低い
### 波掌撃
- L波掌撃 ※パリィ誘い。置きでも強い  
  `5LP > L波掌撃`は4F暴れ潰しになる。※DI確定  
  `2LP > L波掌撃`はDIを返せる  
- M波掌撃
  削り用  
  `5HP > M足刀`に確定反撃できる相手の場合、`5HP > M波掌撃`にする。※ディレイさせるとDIを返せる
- H波掌撃
  ガード時有利フレームを得られる。投げに行く。※DI確定
- OD波掌撃
  削り用
### 竜巻旋風脚
  コンボ用  
  たまに弾抜け  
### 足刀
- L足刀  
  置きで使う
- M足刀 ※一番使う
  ゲージを削りつつラインをあげる  
  先端だと持続になりPPされやすい。`5HP > M足刀`が鉄板  
  H足刀はたまに使うといい味をだせる。PCでSA1OK  
  JPのような、リーチは長いが硬直が長いキャラクターに  
## コンボ
### PC
- `H足刀 > DR > 2HP > CDR > 5MP > CDR > 4HP > CDR > 2HP > H足刀 > M昇竜拳 > SA3` 
### SAゲージ使用
- `OD足刀 > L波掌撃 > SA1`
### リーサル
- `HK > HK > SA1`
- `HK > 2HP > SA2`
- `HK > 5HP > H昇竜拳 > SA3`

## 立ち回り・ゲームプラン

### 1. 基本方針

波動拳で相手の行動を制限し、地上戦でラインを上げ、画面端でリターンを取る。

無理に接触を狙うのではなく、相手の行動にリスクを与えながら、有利な状況を作る。

### 2. ゲームプランの構成

ゲームプランは次の4要素で整理する。

1. **局面**：現在どのような状況か
2. **狙い**：その状況で何を達成したいか
3. **主な行動**：目的を達成するために何をするか
4. **反応と対応**：相手の行動に応じてどう判断を変えるか

### 3. 局面別ゲームプラン

| 局面 | 狙い | 主な行動 |
|---|---|---|
| 中距離 | 相手の行動を制限する | 波動拳、5HP、中足刀 |
| 相手が下がる | ラインを獲得する | 前歩き、波動拳 |
| 相手が前に出る | 接近にリスクを与える | 5HP、2MK、差し返し |
| 相手が飛ぶ | 飛びを咎めて地上戦へ戻す | 昇龍拳、通常技対空 |
| 接触に成功 | ダメージ・運び・ダウンを取る | 竜巻・足刀締めのコンボ |
| 相手が画面端 | 逃げ道を制限して攻める | 打撃・投げ、起き攻め |
| 攻めが終了 | 無理せず状況を再構築する | 間合い調整、波動拳 |

### 4. 相手の反応と対応

#### 相手が下がる

- **狙い**：ラインを上げて画面端へ追い込む
- **行動**：前歩きを基本に、必要に応じて波動拳を使う
- **注意**：無理に中足ラッシュなどで接触を狙わない

#### 相手が前に出る

- **狙い**：接近を咎める
- **行動**：5HP、2MK、置き技、差し返し
- **注意**：技を空振りさせられないよう間合いを管理する

#### 相手が飛ぶ

- **狙い**：飛びを咎め、地上での行動を強制する
- **行動**：昇龍拳、通常技対空
- **注意**：波動拳を撃つ距離とタイミングを調整する

#### 相手がパリィを多用する

- **狙い**：パリィに依存した防御を崩す
- **行動**：前歩きで距離を詰め、投げを狙う
- **注意**：相手のパリィ解除や反撃も観察する

#### 相手が動かない

- **狙い**：安全にラインを上げ、有利な距離を作る
- **行動**：前歩き、間合い調整、波動拳
- **注意**：試合を無理に動かそうとしない

### 5. 基本的な勝ち筋

1. 波動拳・地上技で相手の行動を制限する
2. 相手の反応を観察する
3. 対空・差し返し・前歩きなどで対応する
4. 有利な接触からコンボにつなげる
5. 竜巻・足刀などで運びとダウンを取る
6. 画面端や起き攻めでリターンを得る
7. 攻めが終わったら、再び有利な状況を作る

### 6. 判断の原則

- 相手が下がることも、こちらがラインを獲得する機会になる
- 攻めることと、無理に触りに行くことは違う
- Driveを消費せずに目的を達成できるなら、それも選択肢にする
- 相手の反応に応じて行動を変更する
- 体力差・残り時間・Drive・SA・画面位置によってリスクの取り方を変える
- ゲームプランは固定手順ではなく、実戦で検証・更新する仮説である

### 7. 検証課題

- [ ] 波動拳に対する相手の反応を観察できるか
- [ ] 相手が下がったとき、焦らずラインを上げられるか
- [ ] 5HP・中足刀・2MKを目的に応じて使い分けられるか
- [ ] 接触後に安定してコンボ・運び・ダウンを取れるか
- [ ] 攻めが終わったとき、無理に継続せず立て直せるか
- [ ] 想定外の展開でもゲームプランを修正できるか
